# Fixed-opening initial H5 derivation

This freezes a separate conditional mathematical derivation for the initial
salted H5/correction transition in the B6 bounded driver. The
[note](../../../specs/parliament_ballot_b6_h5_fixed_opening.md) starts only
after the explicitly assumed ideal-row entry and atomic selective schedule.
It does not complete G5–G6 or qualify a production profile.

The gate-domain construction defers the current uniform prefix mask and
salt into a fresh-location sampler. It derives an isolated bound uniform in
independently selected admissible openings, including a fixed fallback,
with prior and future quantum queries retained. The exact endpoint uses
chronological overwrites and charges the own-label equality exception.
The frozen arguments and numerical security ledger are unchanged.

`receipt.json` pins the note, 14 source/specification inputs, source
excerpts, and the versioned primary QROM theorem PDF by URL and SHA-256.
It records deterministic namespace/parameter checks and two completed
automated local consistency reviews. Those reviews are not owner acceptance
or independent cryptographic review. The thirteenth-to-fourteenth input
addition, `framing.rs`, has its later observation time recorded explicitly.
No code or runtime tests were added for this mathematical note.

The namespace check computes the frozen frame from the printed descriptor
digests and checks the source test prefixes; it does not rebuild CRT table
digests or descriptors. The fixed 162-byte address layout is injectively
parsed, the four namespace prefixes are distinct, and the row gate counts
are 704 and 696. These checks are not a compiled-source proof.

From the repository root, verify the frozen files with:

```sh
shasum -a 256 -c docs/validation/parliament_ballot_h5_fixed_opening/SHA256SUMS
```

The receipt's source hashes identify reviewed inputs, not their
authenticity. The remaining obligations include reaching the ideal entry,
actual primitive-interface reductions, the mask/deletion composition,
complete computational resources and independent review. Production remains
gated; no primitive advantage or ledger replacement is adopted here.
