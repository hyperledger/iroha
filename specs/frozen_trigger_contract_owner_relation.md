# Frozen trigger-contract original relation

The sole Set semantic phase engine checks data, pipeline, time and by-call
references, then canonical contract rows in key order. Each row retains the
original lookup-hash, deployable-code-hash and exact positive reference-count
predicates, followed by the original missing-contract check. The public current
validator keeps its original String diagnostics and ordinary counter. The checked
path shares those predicates and uses a fixed counter charged to the caller's
original allocation pool. Neither path repairs rows or adds artifact validity,
execution admission, ID/active-index equality, ownership, permissions or ABI checks.

The checked path traverses Current before Predecessor. Predecessor is the canonical
History two-head merge over the sole sealed native current/undo views. Every
physical row, including masked current values, undo absence and no-op writes, is
advanced. Keys and values are borrowed; no sorted row bank or cloned source is
created. Trigger names compare all UTF8 operand bytes. Contract keys compare both
full32-byte hashes. Counter scans visit the complete initialized prefix even after
a match or a nonzero count; Current reset preserves the same backing allocation.

L1 is an explicit conservative local admission proxy: enumerated source-event
capsules plus full byte footprints. It is not CPU cost, gas, physical custody,
serialization admission or a descriptor maximum. Native inline cursor construction
pays29B+44; every next call, including terminal calls, pays17B+26, where B is the
native address width. These envelopes include original debug paths. Geometry
checks seven actual additions and eight length observations. Typed hashing calls
the actual HashOf::try_new on the original IvmBytecode with its current default
Norito flags and schema. T(L)=42+2L+2p, where p is the compact prefix width of L+8;
the separately billed local helper has3 events. Deployable hashing follows only a
successful lookup check and calls the original contract_code_hash with the exact
31-byte `iroha:ivm:contract-artifact:v1\0` domain and all artifact bytes. D(L)=36+L
plus its3 local helper events. No new encoder, header, domain or flag override exists.

The scoped scheduling references include the encoder's prepaid original current
cursor and complete possible native next calls. On64-bit sources, independently
derived capture controls are empty63507, singleton70000, masked/no-op/absence77066,
three distinct compact boundaries85792 and full255-byte UTF8 noop72814. These are
literal controls for declared fixture shapes, not shape restrictions or worst-case
limits. More work refuses locally without changing State validity, gas or config.
The original zero-action bad-code prefix is30547 and allocates zero counter backing.

Committed custody retains the five actual read owners through semantic checking,
encoding and all five materialized native currentness Results. Validation and
encoding outcomes remain held until those fences. Readers drop before the counter's
charge refunds; the State callback then checks its final generation fence before
returning any outcome. Frozen custody retains all ten original Set targets in one
common Ordinary/Replace mode and only the actual State pool, through the same
five-source predicate and borrowed bytecode encoder. Partial, foreign, reacquiring
or released fields never refresh their source. The final State fence follows the
held outcome and original-owner drops.

Semantic failures keep the original SourceValidation String boundary. Local work,
physical counter admission/allocator, native publication and canonical typed-hash
failures remain distinct. Typed-hash failure moves the full original norito::Error;
its bounded equality descriptor does not claim original cause identity. Original
resource/depth/count/length/allocation fields and source() remain available, without
another diagnostic allocation, boxing, rendering or scope reset.

The registered phase-order controls retain different malformed images: Current's
code mismatch precedes Predecessor's count mismatch, while a valid Current must
still reject that malformed Predecessor. Inherited count tests call the shipping
typed-hash boundary from a test-only enclosing serializer. The original L3 bytecode
measurement consumes eleven bytes; a ten-byte allowance preserves its original
I/O error, and catching that error still produces the original sticky
LengthMismatch. Nested parent accounting, outer flags and unwind restoration use
the existing Norito count guard. These source controls await execution.

Core already registers a private thread-local global allocator census for its
unit tests; a separate test binary is unnecessary. The new cold/warm controls use
that existing observer for actual native cursor construction, complete current
and predecessor physical tails, borrowed name/hash comparisons, full fixed-counter
tails and the shipping typed/deployable hash calls. Hash workers perform their
first measured call before computing an expected hash on that thread. Fixtures,
held read owners and funded counter backing are prepared outside those zero-call
observation windows. A positive Box allocation checks the census. The exact
CounterCell layout refusal separately checks the real fallible allocation,
original-pool peak, refusal refund, successful retry and final-owner refund.
These controls await execution; the census counts successful allocation and
reallocation calls, not refused null returns or deallocations. The successful
capture deliberately allocates its fixed counter backing from the original pool,
so it is not a zero-allocation capture. No global allocator result is inferred
from the earlier pool or synthetic next-call controls.
